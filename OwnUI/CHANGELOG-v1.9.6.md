# 栖页音乐 1.9.6 / Build 89 / Full CarPlay v19

基于用户实际安装的完整 v18（SHA256：68c12f0e1a815d5a0631287a82d856634ac141f14f783bf0b028e1b6e9999480）。保留全部资源、自己的界面、音乐房间、聊天、原生音频与 CarPlay，最低系统继续为 iOS 15.0，兼容 iOS 15.5。

- 外部音频设备断开后立即暂停当前原生解码器，本机暂停保护不会被房间同步、重新连接蓝牙、系统中断恢复覆盖，也不会向房间发送全体暂停。
- 防止异步音源加载、FLAC 打开、已排队的播放命令晚于暂停完成后又开始播放。原生保护直接暂停已有 TrackPlayer / FLAC 模块，不等待后台 RN JavaScript 恢复。
- 暂停保护期间继续跟随房间歌曲信息；点击播放后按房间当前进度恢复本机，避免重新发起切歌令整个房间回到开头。
- CarPlay 从 UIKit 当前连接场景恢复，允许系统重用已断开过的场景/控制器；已失效的旧连接不能阻挡新场景，旧异步回调不能覆盖新连接。
- 监听场景断开通知；新音频路由连接时对已经存在的前台车机场景作有限次数恢复。不会创建系统没有提供的 CarPlay 场景，也不增加常驻轮询。
- CarPlay 原生连接事件可直接激活原生房间协调，减少对手机 WebKit / RN 页面恢复的依赖。

验证包括 JavaScript 异步时序回归、Foundation 状态与顺序测试、真实 iOS 模拟器本地 FLAC 播放/音频路由通知/房间状态协调，以及生产 CarPlay 生命周期与原生解码器保护代码的测试。模拟器不等于真实蓝牙链路和真实车机；安装后仍需在用户的 iOS 15.5 与车机上复测。
