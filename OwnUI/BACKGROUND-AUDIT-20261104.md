## 已确认的问题与修复

| 优先级 | 问题及触发方式 | 修复 |
| --- | --- | --- |
| P1 | `WebController` 仅在前台收到 WebKit 进程终止回调时重载；后台回收事件被丢弃，场景恢复时也没有补查。 | 记录待恢复状态；监听手机激活；检查页面握手和 bridge 存活；限时恢复内置页面，并提供原生重试界面。 |
| P1 | 普通房间进度来自音频状态回调，而主动解码器探测只在前台运行。音频继续播时，房间上报可能停止。 | 原生房间心跳独立触发进度上报；后台按 4 秒间隔探测现有解码器，前台保留 1 秒间隔；共享上报节流。 |
| P1 | 重连时仍是同一首，最新事件已成为 progress，之前漏掉的 seek/play 不会补回。 | 重连首个有效快照校正一次位置和播放意图，正常 progress 不反复 seek。输出断开保护仍必须由用户操作解除。 |
| P1 | 切歌 HTTP 请求失败后，`pendingID` 保留，后续快照可能被当作旧确认一直拒绝。 | 仅释放对应失败命令的确认标记，保护更晚的新命令；失败与拒绝响应可以恢复到权威房间状态。 |
| P1 | 起床/冷启动时绑定查询失败，只记录错误，之后可能没有新的事件触发再次查询。 | 增加有上限退避的绑定重试，断开或切换账号时取消旧重试。 |
| P1 | App 优先使用原平台 `songmid`，规范库和新版服务端可能使用 `id`；两个平台的数字 ID 也可能相同。 | 规范 ID 优先；没有规范 ID 时包含平台；遥测沿用服务端协商的 songKey，并发送 playbackRevision。 |
| P2 | Web 重新加载后从 1 开始复用请求号，旧异步回调可能完成新页面的同号请求。 | 每次载入增加页面代次，丢弃旧页面完成回调。 |
| P2 | WebKit 内容控制器强持有脚本处理器，而脚本处理器就是持有 WebView 的控制器。 | 使用弱引用代理，释放时移除观察者和计时器；后台不向不可见的聊天页面反复执行 JS。 |
| P2 | App 编辑 `[A,B,A,C]` 队列后，直接 firstIndex 会把第二个 A 改成第一个 A。 | 验证并优先保留界面提交的实际队列位置。 |
| P2 | 断网时多个选歌依次积压，恢复后可能先切过已经过时的歌曲。 | 保持在途请求顺序；排队选歌只保留最新完整选择，重复 seek/mode/play/pause 合并。 |
| P2 | 账号变化后，原 API 请求直接丢弃回调，调用方可能一直等待。 | 以取消错误结束该请求，调用方继续用账号、命令和页面代次隔离旧结果。 |
| 构建 | 后续音质修复把解析结果改成 `ResolvedAudio`，下载模块仍解构旧 tuple，当前分支无法完整编译。 | 下载模块使用新结果的 URL 与实际播放格式；该项是源码分支的构建问题，不宣称已安装的 build 94 会在运行时触发编译错误。 |

同时减少普通播放/暂停/拖动命令重复携带整条队列。房间 HTTP 暂时失败只更新房间连接错误，不直接把正常工作的音频解码器置为失败。

## 检查方式

新增 `.github/workflows/background-recovery.yml`，执行以下检查：

1. 原有音频驱动、原生网页 bridge、歌词、本地音源的 42 项 JavaScript 回归。
2. Swift `Core.swift` 的队列、身份、时钟、文件和恢复状态测试。
3. 编译生产 `RoomClient`，用确定性的 API/音频边界检查重连校准、失败控制、绑定重试、旧确认隔离和选歌合并。
4. iOS 模拟器运行实际 `WebController`、内置 HTML/JS 和原生页面握手；模拟后台回收回调、前台 bridge 丢失，确认重载不替换原生播放器，并检查控制器可以释放。
5. 原有 CarPlay 场景复用、控制器更新、旧连接回调和遥控所有权的模拟器回归。

第 4 项通过测试用的场景可见性开关模拟回收回调，不等于真机系统长时间内存回收测试。第 3 项使用生产房间逻辑及测试 API/音频边界，不等于已连接你的真实服务器或车机。CI 的每次运行结果与原始报告保存在对应 Actions 记录中。

## 部署与剩余验证

- 修改 App 源码不会改变手机上已安装的 IPA。需要从修复分支重新构建、按原方式签名安装，才能验证 App 侧修复。此前 v2.9.6 服务器升级包只更新服务器和网页。
- 这次不修改已安装的 App，也未连接用户服务器或真实车机；不承诺所有硬件和所有锁屏时长均已验证。
- 真机应检查：播放中锁屏 30 分钟；另一成员切歌/暂停/拖动；网络切换和短时断网后重连；后台久置后重新连接车机；来电中断后恢复；退出车机后不自动从手机扬声器出声；返回 App 页面可以恢复。
- iOS 可在暂停且没有有效后台任务时挂起整个进程。这里修复播放中的同步与重新唤醒后的恢复，不通过静音音频、私有后台权限等方式强行常驻。
