# 栖页音乐 1.9.9 / Build 92 / Full CarPlay v22

修正原生 URLSession 桥对 `application/x-www-form-urlencoded` 请求的编码。旧代码使用 URLComponents 的 URL 查询编码，留下字面量 `+`；网易 weapi 的 Base64 密文包含 `+`，服务端按表单规则解码后会将其变成空格，返回空内容。歌单元数据接口可成功，但补全歌曲详情失败，旧 SDK 随后反复重取整张歌单，最终显示 `try max num`。

本次仅将表单键和值按 UTF-8 字节正确编码，保留 `+`、`/`、`=`、`&`、百分号与中文原值。未更换平台 SDK、歌单 ID、音源脚本或音乐服务器，也未改动 UI、房间同步、音频解码和锁屏交接逻辑。

## 验证

- 严格 HTTP 服务检查通过生产 JavaScriptCore / URLSession 实际发出的表单字节；同一检查要求上一版编码器明确失败，并要求修正版本成功。
- 使用生产 JavaScriptCore / URLSession 直接请求网易热门歌单和两个真实歌单详情，检查返回歌曲元数据。该检查不使用提供方响应夹具或服务器转发。
- 继续执行页面渲染、慢音源启动、离线播放、蓝牙暂停和 CarPlay 模拟器检查。

原生表单缺陷也存在于 v19；“过去正常”不能排除同一缺陷只在密文出现特殊字符、或歌单需要补全歌曲时触发。外部平台可用性会随网络与平台规则变化，测试通过不等于所有平台或 iOS 15.5 实机均已验证。
