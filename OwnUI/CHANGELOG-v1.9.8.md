# 栖页音乐 1.9.8 / Build 91 / Full CarPlay v21

针对 v20 实机反馈的页面变慢、歌单歌曲不能正常显示，收紧启动和媒体控制路径。

- 不再全局修改 UIKit / MediaPlayer 方法，也不删除系统或原 SDK 的遥控目标。锁屏信息异步合并提交；暂停的播放历史、音量恢复与纯浏览均不初始化媒体服务或绘制封面。
- 只在实际音频加载后初始化播放 SDK；锁屏按钮事件从 SDK 原生发出点直接进入 Swift，避免后台 JS 延迟后的二次转发。
- 本地内置 SDK 就绪即允许歌单、搜索等接口使用。已保存的用户音源后台恢复，不再让慢音源的初始化握手挡住全部音乐请求；真正解析播放地址仍等待音源恢复，取消的旧播放请求不会在恢复后执行。
- 保留无清空队列的切歌交接、完整卡片过渡、封面代次保护、蓝牙断开本机暂停、系统中断处理与 CarPlay 重连修复。
- 新增恢复登录与 500 首播放历史的 iOS Simulator 验证，使用故意延迟的已保存音源，检查内置接口先返回、音频解析等待源就绪，并通过真实 WebKit / Swift 桥 / JavaScriptCore SDK / URLSession 路径获得和渲染歌单歌曲。

测试使用受控的提供方响应，不代表所有外部平台在真实网络上始终可用；真实 iOS 15.5 的启动速度、锁屏与物理车机仍需实机复测。

完整版基于 v20（SHA256 `94884ab3a6c627172a0abdb3e7592e7de8123566c8b37624faaa3da2596ab80b`）重建，保留全部原文件与主程序代码段、自己的界面、房间和聊天。最低部署目标仍为 iOS 15.0。
