# 栖页音乐 1.9.7 / Build 90 / Full CarPlay v20

针对用户录屏中切歌后锁屏短暂出现“未在播放”、系统推荐及按钮变灰的问题。

- 普通切歌不调用 SDK `reset` 或 `stop`，也不先清空整个播放队列。先暂停旧音频，把新歌加入并切换到新歌，再倒序移除旧条目；控制事件和播放会话跨曲保留，底层队列维持一个有效条目。
- 锁屏信息从 Swift 直接交给原生协调器，不经过后台可能暂停的 React Native 队列。原生是唯一的信息与按钮状态写入方，阻止旧组件的清空、停止状态、迟到封面以及注销控制事件覆盖当前状态。
- 新音源解析/打开期间保留上一份完整卡片，准备就绪后替换。缓冲中的播放意图不会短暂变成暂停按钮；真正暂停、蓝牙断连保护仍立即反映到锁屏。
- 封面缓存复用，网络与本机图片在后台下载/缩略解码；完成后按代次更新。过期回调不能覆盖新歌，失败使用稳定的音乐占位封面，不中途清空封面。
- 原生锁屏按钮直接调用同一个 Swift 播放队列；上一首/下一首保持可用，快进/快退与 15/30 秒跳转禁用。按钮事件在原生记录时间，不会把旧命令误当成蓝牙断开后的新操作。
- 继承 v19 的本机蓝牙断连暂停、房间协调与 CarPlay 热恢复；保留完整底包原有文件、自己的 UI、房间和聊天，最低部署目标仍为 iOS 15.0。

验证包含 JavaScript 时序回归、实际生产原生锁屏协调器的 iOS Simulator 检查，以及原有本机 FLAC、房间音频路由和 CarPlay 生命周期检查。模拟器通过不等于真实 iOS 15.5 锁屏或物理车机验证。
